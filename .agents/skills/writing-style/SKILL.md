# House style

Read the guide for the deliverable, then use
[ai-writing-donts.md](ai-writing-donts.md) for the final prose pass.

- [pull-requests.md](pull-requests.md): commits and PR titles/bodies.
- [issues.md](issues.md): GitHub issues and comments.
- [reference-docs.md](reference-docs.md): API, CLI, spec, and workflow references.
- [tutorials.md](tutorials.md): learning-oriented usage documentation.

Use a practical voice for technically capable peers. Lead with the behavior,
result, or decision. Keep evidence and limitations explicit. Remove hype,
decorative structure, attribution, and generic filler. Preserve harmless human
flourishes when editing someone else's prose.

These guides are adapted from Marin. Describe verifyit and the reader's actual
workflow; introduce task-runner context only when it helps them use the library.
